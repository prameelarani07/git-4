# Git Version Control DevOps Project

## Objective

Demonstrate Git and GitHub version control best practices.

## Git Workflow

* Created `main` branch
* Created `dev` branch
* Created `feature` branch
* Created Pull Request from `feature` → `dev`
* Created Pull Request from `dev` → `main`
* Created Git tag `v1.0.0`

## Tools Used

* Git
* GitHub

## Outcome

Successfully demonstrated branching, commits, pull requests, merging, `.gitignore`, documentation, and Git tags.
